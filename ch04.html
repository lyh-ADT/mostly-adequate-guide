第 04 章：柯里化

第 04 章：柯里化

没有你，这日子可怎么过

我爸以前跟我讲过：有些东西，你没有它也能活，直到你拥有了它。微波炉算一个。智能手机算另一个。咱们当中上点年纪的人都记得，没有互联网的日子照样过得挺充实。对我来说，柯里化（currying）也在这份清单上。

概念很简单：你可以用比它预期更少的参数去调用一个函数。它会返回一个函数，等着接收剩下的参数。

你可以一次性把它调用完，也可以一个参数一个参数地零喂进去。

const add = x => y => x + y;
const increment = add(1);
const addTen = add(10);

increment(2); // 3
addTen(2); // 12

这里我们做了一个函数 add，它接收一个参数，返回一个函数。调用它之后，返回的那个函数就通过闭包把第一个参数从此刻起记在了心里。不过，每次都把两个参数一股脑传进去有点烦人，所以我们可以用一个叫 curry 的特殊辅助函数，让这种函数的定义和调用都轻松些。

咱们先弄几个柯里化的函数来玩玩。从现在起，我们要召唤的 curry 函数，就是附录 A：必备函数支持里定义的那个。 

const match = curry((what, s) => s.match(what));
const replace = curry((what, replacement, s) => s.replace(what, replacement));
const filter = curry((f, xs) => xs.filter(f));
const map = curry((f, xs) => xs.map(f));

我遵循的这个模式简单却重要：我把要操作的数据（String、Array）刻意放在了最后一个参数的位置。用起来你就明白为什么了。

（/r/g 这种语法是正则表达式，意思是匹配每一个字母 'r'。感兴趣的话可以读读更多关于正则表达式的内容。）

match(/r/g, 'hello world'); // [ 'r' ]

const hasLetterR = match(/r/g); // x => x.match(/r/g)
hasLetterR('hello world'); // [ 'r' ]
hasLetterR('just j and s and t etc'); // null

filter(hasLetterR, ['rock and roll', 'smooth jazz']); // ['rock and roll']

const removeStringsWithoutRs = filter(hasLetterR); // xs => xs.filter(x => x.match(/r/g))
removeStringsWithoutRs(['rock and roll', 'smooth jazz', 'drum circle']); // ['rock and roll', 'drum circle']

const noVowels = replace(/[aeiou]/ig); // (r,x) => x.replace(/[aeiou]/ig, r)
const censored = noVowels('*'); // x => x.replace(/[aeiou]/ig, '*')
censored('Chocolate Rain'); // 'Ch*c*l*t* R**n'

这里演示的，是给函数“预装”一两个参数的能力——作为回报，你会得到一个新函数，它记着这些参数。

我建议你把 Mostly Adequate 仓库克隆下来（git clone https://github.com/MostlyAdequate/mostly-adequate-guide.git），把上面的代码复制一份，然后 在 REPL 里试一试。curry 函数，以及附录里定义的任何东西， 都能在 support/index.js 模块里找到。

或者，看看 npm 上发布的版本：

npm install @mostly-adequate/support

不只是个双关，还有独门酱料

柯里化在很多地方都有用。只要给基础函数喂几个参数，我们就能造出新函数——hasLetterR、removeStringsWithoutRs 和 censored 就是例子。

我们还能把任何处理单个元素的函数，用 map 一包，就变成处理数组的函数：

const getChildren = x => x.childNodes;
const allTheChildren = map(getChildren);

给一个函数传比它预期更少的参数，通常叫做部分应用（partial application）。部分应用能砍掉一大堆样板代码。想想上面那个 allTheChildren，如果改用 lodash 里没柯里化的 map，会写成什么样（注意参数顺序不一样）：

const allTheChildren = elements => map(elements, getChildren);

我们通常不会去定义一个专门处理数组的函数，因为直接内联调用 map(getChildren) 就行了。sort、filter 以及其他高阶函数（higher-order function）也是这个理（高阶函数就是接收函数或返回函数的函数）。

聊纯函数（pure function）的时候我们说过，它们是 1 个输入对应 1 个输出。柯里化干的正是这件事：每个单独的参数都返回一个新函数，等着剩下的参数。老伙计，这就是 1 个输入对 1 个输出。

哪怕输出是另一个函数也没关系——它照样算纯的。我们确实允许一次传多个参数，但那只是图省事，把多余的 () 去掉罢了。

总结

柯里化很顺手，我本人就非常享受每天跟柯里化函数打交道。它是腰带上的一件工具，能让函数式编程（functional programming）少些啰嗦、少些煎熬。

只要传几个参数，我们就能随手造出新的、有用的函数；额外的好处是，哪怕参数变多了，我们依然守住了数学意义上的函数定义。

咱们再去弄一件必备工具，它叫 compose。

function inspect(x) {
  if (x && typeof x.inspect === 'function') {
    return x.inspect();

  function inspectFn(f) {
    return f.name ? f.name : f.toString();

  function inspectTerm(t) {
    switch (typeof t) {
      case 'string':
        return `'${t}'`;

}

// NOTE 一个稍微加强版的 `curry`，它还会记录一个函数到底是被部分应用了，
// 还是一次性传齐了所有参数。
// 这有助于在验证练习时给出更有用的提示。
function curry(fn) {
  assert(
    typeof fn === 'function',
    typeMismatch('function -> ?', [getType(fn), '?'].join(' -> '), 'curry'),
  );

  const arity = fn.length;

  return namedAs(fn.name, function $curry(...args) {
    $curry.partially = this && this.partially;

    if (args.length < arity) {
      return namedAs(fn.name, $curry.bind({ partially: true }, ...args));
    }

    return fn.call(this || { partially: false }, ...args);
  });
}


// NOTE 一个稍微加强版的 `compose`，它还会记录被调用函数的链条。
// 最终，用 `compose` 创建出来的函数会带一个 `callees` 变量，
// 里面是所有被调用函数的名字。
// 这有助于在验证练习时给出更有用的提示。
function compose(...fns) {
  const n = fns.length;

  return function $compose(...args) {
    $compose.callees = [];

    let $args = args;

    for (let i = n - 1; i >= 0; i -= 1) {
      const fn = fns[i];

      assert(
        typeof fn === 'function',
        `Invalid Composition: ${ordinal(n - i)} element in a composition isn't a function`,
      );

      $compose.callees.push(fn.name);
      $args = [fn.call(null, ...$args)];
    }

    return $args[0];
  };
}

class Map {
  constructor(x) {
    assert(
      typeof x === 'object' && x !== null,
      'tried to create `Map` with non object-like',
    );

    this.$value = x;
  }

  inspect() {
    return `Map(${inspect(this.$value)})`;
  }

  getType() {
    const sample = this.$value[Object.keys(this.$value)[0]];

    return `(Map String ${sample ? getType(sample) : '?'})`;
  }

  insert(k, v) {
    const singleton = {};
    singleton[k] = v;
    return new Map(Object.assign({}, this.$value, singleton));
  }

  reduce(fn, zero) {
    return this.reduceWithKeys((acc, _, k) => fn(acc, k), zero);
  }

  reduceWithKeys(fn, zero) {
    return Object.keys(this.$value)
      .reduce((acc, k) => fn(acc, this.$value[k], k), zero);
  }

  map(fn) {
    return new Map(this.reduceWithKeys((obj, v, k) => {
      obj[k] = fn(v); // eslint-disable-line no-param-reassign
      return obj;
    }, {}));
  }

  sequence(of) {
    return this.traverse(of, x => x);
  }

  traverse(of, fn) {
    return this.reduceWithKeys(
      (f, a, k) => fn(a).map(b => m => m.insert(k, b)).ap(f),
      of(new Map({})),
    );
  }
}

class Maybe {
  static of(x) {
    return new Maybe(x);
  }

  get isNothing() {
    return this.$value === null || this.$value === undefined;
  }

  get isJust() {
    return !this.isNothing;
  }

  constructor(x) {
    this.$value = x;
  }

  ap(f) {
    return this.isNothing ? this : f.map(this.$value);
  }

  chain(fn) {
    return this.map(fn).join();
  }

  inspect() {
    return this.isNothing ? 'Nothing' : `Just(${inspect(this.$value)})`;
  }

  getType() {
    return `(Maybe ${this.isJust ? getType(this.$value) : '?'})`;
  }

  join() {
    return this.isNothing ? this : this.$value;
  }

  map(fn) {
    return this.isNothing ? this : Maybe.of(fn(this.$value));
  }

  sequence(of) {
    return this.traverse(of, x => x);

function curry(fn) {
  assert(
    typeof fn === 'function',
    typeMismatch('function -> ?', [getType(fn), '?'].join(' -> '), 'curry'),
  );

  const arity = fn.length;

  return namedAs(fn.name, function $curry(...args) {
    $curry.partially = this && this.partially;

    if (args.length < arity) {
      return namedAs(fn.name, $curry.bind({ partially: true }, ...args));
    }

    return fn.call(this || { partially: false }, ...args);
  });
}

// 里面是所有被调用函数的名字。
// 这有助于在验证练习时给出更有用的提示。
function compose(...fns) {
  const n = fns.length;

  return function $compose(...args) {
    $compose.callees = [];

    let $args = args;

    for (let i = n - 1; i >= 0; i -= 1) {
      const fn = fns[i];

      assert(
        typeof fn === 'function',
        `Invalid Composition: ${ordinal(n - i)} element in a composition isn't a function`,
      );

      $compose.callees.push(fn.name);
      $args = [fn.call(null, ...$args)];
    }

    return $args[0];
  };

const getType = (x) => {
  if (x === null) {
    return 'Null';
  }

  if (typeof x === 'undefined') {
    return '()';
  }

    return `[${x[0] ? getType(x[0]) : '?'}]`;
  }

  if (typeof x.getType === 'function') {
    return x.getType();
  }

  if (x.constructor && x.constructor.name) {
    return x.constructor.name;
  }

  return capitalize(typeof x);
};

// NOTE 一个稍微加强版的 `curry`，它还会记录一个函数到底是被部分应用了，
// 还是一次性传齐了所有参数。
// 这有助于在验证练习时给出更有用的提示。
function curry(fn) {
  assert(
    typeof fn === 'function',
    typeMismatch('function -> ?', [getType(fn), '?'].join(' -> '), 'curry'),
  );

  const arity = fn.length;

  return namedAs(fn.name, function $curry(...args) {
    $curry.partially = this && this.partially;

    if (args.length < arity) {
      return namedAs(fn.name, $curry.bind({ partially: true }, ...args));
    }

    return fn.call(this || { partially: false }, ...args);
  });
}


// NOTE 一个稍微加强版的 `compose`，它还会记录被调用函数的链条。
// 最终，用 `compose` 创建出来的函数会带一个 `callees` 变量，
// 里面是所有被调用函数的名字。
// 这有助于在验证练习时给出更有用的提示。
function compose(...fns) {
  const n = fns.length;

  return function $compose(...args) {
    $compose.callees = [];

    let $args = args;

    for (let i = n - 1; i >= 0; i -= 1) {
      const fn = fns[i];

      assert(
        typeof fn === 'function',
        `Invalid Composition: ${ordinal(n - i)} element in a composition isn't a function`,
      );

      $compose.callees.push(fn.name);
      $args = [fn.call(null, ...$args)];
    }

    return $args[0];
  };
}

class Map {
  constructor(x) {
    assert(
      typeof x === 'object' && x !== null,
      'tried to create `Map` with non object-like',
    );

    this.$value = x;
  }

  inspect() {
    return `Map(${inspect(this.$value)})`;
  }

  getType() {
    const sample = this.$value[Object.keys(this.$value)[0]];

    return `(Map String ${sample ? getType(sample) : '?'})`;
  }

  insert(k, v) {
    const singleton = {};
    singleton[k] = v;
    return new Map(Object.assign({}, this.$value, singleton));
  }

  reduce(fn, zero) {
    return this.reduceWithKeys((acc, _, k) => fn(acc, k), zero);
  }

  reduceWithKeys(fn, zero) {
    return Object.keys(this.$value)
      .reduce((acc, k) => fn(acc, this.$value[k], k), zero);
  }

  map(fn) {
    return new Map(this.reduceWithKeys((obj, v, k) => {
      obj[k] = fn(v); // eslint-disable-line no-param-reassign
      return obj;
    }, {}));
  }

  sequence(of) {
    return this.traverse(of, x => x);
  }

  traverse(of, fn) {
    return this.reduceWithKeys(
      (f, a, k) => fn(a).map(b => m => m.insert(k, b)).ap(f),
      of(new Map({})),
    );
  }
}

class Maybe {
  static of(x) {
    return new Maybe(x);
  }

  get isNothing() {
    return this.$value === null || this.$value === undefined;
  }

  get isJust() {
    return !this.isNothing;
  }

  constructor(x) {
    this.$value = x;
  }

  ap(f) {
    return this.isNothing ? this : f.map(this.$value);
  }

  chain(fn) {
    return this.map(fn).join();
  }

  inspect() {
    return this.isNothing ? 'Nothing' : `Just(${inspect(this.$value)})`;
  }

  getType() {
    return `(Maybe ${this.isJust ? getType(this.$value) : '?'})`;
  }

  join() {
    return this.isNothing ? this : this.$value;
  }

  map(fn) {
    return this.isNothing ? this : Maybe.of(fn(this.$value));
  }

  sequence(of) {
    return this.traverse(of, x => x);
  }

  traverse(of, fn) {
    return this.isNothing ? of(this) : fn(this.$value).map(Maybe.of);
  }
}


class Task {
  constructor(fork) {
    assert(
      typeof fork === 'function',
      'invalid `fork` operation given to Task constructor. Use `Task.of` if you want to lift a value in a default minimal Task context.',
    );

    this.fork = fork;
  }

  static of(x) {
    return new Task((_, resolve) => resolve(x));
  }

  static rejected(x) {
    return new Task((reject, _) => reject(x));
  }

  ap(f) {
    return this.chain(fn => f.map(fn));
  }

  chain(fn) {
    return new Task((reject, resolve) => this.fork(reject, x => fn(x).fork(reject, resolve)));
  }

  inspect() { // eslint-disable-line class-methods-use-this
    return 'Task(?)';
  }

  getType() { // eslint-disable-line class-methods-use-this
    return '(Task ? ?)';
  }

  join() {
    return this.chain(x => x);
  }

  map(fn) {
    return new Task((reject, resolve) => this.fork(reject, compose(resolve, fn)));
  }
}
